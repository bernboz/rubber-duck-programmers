# Rubber Duck Programmers

A simple static team website for CPSC 4140 at Clemson University. No installation or build step is required. Open `index.html` in a browser to preview it.

## Publish free with GitHub Pages

1. Create a **public** GitHub repository named `rubber-duck-programmers`.
2. Upload the **contents** of this folder to the repository's `main` branch. Keep `index.html`, `styles.css`, `.nojekyll`, and the `assets` folder at the repository root, rather than inside another folder.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/ (root)**, then click **Save**.
5. Wait for deployment, then use the website link shown in Settings → Pages. It will normally be `https://YOUR-USERNAME.github.io/rubber-duck-programmers/`.

Updates to the files on `main` publish automatically. GitHub says publication can take up to 10 minutes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Updating the site

- Names and the document link are in `index.html`.
- Appearance and responsive layout are in `styles.css`.
- Headshots are in `assets/`, in the requested order: Bennett, Bernard, Amanda, Anabel, Ashok. The original images are preserved; CSS crops their display into matching squares.
- Ensure the Google Doc's sharing settings let your intended visitors view it. Publishing this website does not change the document's permissions.
